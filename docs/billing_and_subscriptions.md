# Billing, Subscriptions & Invoicing

## 1. Subscription Tiers
* **Free Developer Tier**: 10,000 monthly API calls, 1 GB vector storage, community Discord support.
* **Pro Tier ($49 / month)**: 500,000 monthly API calls, 25 GB vector storage, 99.9% uptime SLA, priority email support within 4 hours.
* **Enterprise Tier (Custom Pricing)**: Unlimited API calls, dedicated multi-region cluster, 99.99% uptime SLA, dedicated Technical Account Manager (TAM) with 15-minute response SLA.

## 2. Invoicing & Billing Cycle
* All recurring subscription charges are automatically processed on the **1st calendar day of each month**.
* Accepted payment methods include major credit cards (Visa, MasterCard, Amex), Wire Transfer (ACH/SEPA for invoices exceeding $1,000), and AWS Marketplace billing integration.

## 3. Refund & Cancellation Policy
* Users can cancel their subscription at any time from the billing portal. Cancellations take effect at the end of the current billing cycle.
* Unused API call quotas do not roll over to subsequent billing months.
